# 我的星星农场

真实时间制、纯前端的像素农场 H5 游戏。支持电脑浏览器与手机网址访问，无登录、后端、体力或人物移动机制。按已确认的「比例调整版」UI 实现暖色地图、木质按钮和羊皮纸操作面板。

## 本地运行

需要 Node.js 22.12+（或 20.19+）。

```sh
npm install
npm run dev
```

电脑打开终端打印的 Local 地址（默认 `http://localhost:5173/`）。手机与电脑连接同一 Wi-Fi，打开终端打印的 Network 地址，例如 `http://192.168.x.x:5173/`。需要电脑持续运行服务，系统防火墙允许局域网访问。不要在手机上输入 `localhost`，它指向手机自己。

```sh
npm test        # 游戏规则、离线结算、导入校验与多标签页冲突测试
npm run build   # TypeScript 严格检查 + 静态构建 + 离线缓存清单
npm run preview
```

`dist/` 是完整静态产物。部署到任意静态网站服务的**域名根目录**，使用 HTTPS 后即可让电脑、手机通过同一个公网网址访问。当前仓库没有绑定公网托管服务，不包含已发布的公网地址。不支持直接双击 `index.html` 或 `file://` 运行。子路径部署需要同步调整 Vite base、CSS 资源路径与 manifest，当前默认根目录。

## 已实现的玩法

- 多存档创建与农场命名、自动保存、改名、JSON 备份/导入。导入严格校验并创建独立副本，不覆盖已有农场。
- 首页底部为「背包 / 委托 / 设置」；「管理存档」位于设置内。委托面板分「进行中 / 已完成」标签，只显示已接取的委托；完成时永久保存完成时间与奖励，刷新、切换存档及导入导出后保留。旧 v1 存档自动初始化为空的完成记录，旧版已移除的完成记录无法追溯。
- 大地图五大板块：农场、牧场、鱼塘、小镇、神秘商店。手机竖屏；桌面增加侧栏和农场手记。
- 固定 6×5（30 块）农田：开垦、选种、种植、浇水、收获。浇水将剩余时间减半；种子不足不能播种。初始开垦中央 12 块；点击荒地开垦、在下方种子篮选种后点空地播种、未浇水作物浇水、成熟作物收获。移除方向选地按钮，保留详情面板与键盘方向选地。320px 小屏每格约 45px。
- 开垦、浇水、收获熟练度 Lv.1–4，扩大单次操作范围；Lv.3 收获解锁一键收获。Lv.3 浇水使之后播种的成长时间减少 10%。星陨水壶进一步减少之后播种的时间。
- 牧场购买鸡、鸭、兔子、牛、绵羊、猪、虚空鸡、喂食、每小时抚摸一次、收取鸡蛋/牛奶。每次喂食产出一份，收取后需再次喂食；不会无限自动消耗饲料。好感度 3/7 对应银/金品质，品质提高售价。最多 8 只动物。
- 购买鱼苗、放养、喂鱼、按现实 4 小时成长、收网、鱼塘升级扩容。指针垂钓连续成功 3 次钓起，失误 3 次重新尝试，成功后冷却 1 分钟。
- 本地日期每天 00:00 将委托补充至 3 个槽位。接取后才开始 24/48 小时倒计时；可从背包交付，先消耗普通品质。过期移除，无惩罚；已完成/过期槽位等次日补充。
- 金币商店与背包出售；神秘商店只收委托奖章，提供古代种子、工具和地图装扮。工具与装扮不重复兑换。
- 离线最多计算 4 小时。已成熟作物、牧场产出和长成的鱼进入离线仓库，确认收取后进入背包。超出上限的时间不推进剩余成长，防止关闭后一次推进任意长时间。已喂食动物最多结算该次产出。
- 默认静音，可开启原创 24 秒合成旋律与短音效；后台停止音频与垂钓动画。收获物品飘入背包，支持减少动态效果偏好。
- 生产版本提供 Service Worker 离线缓存；首次在线加载并完成缓存后可离线打开（要求 HTTPS 或 localhost）。缓存失败不影响在线游戏。

## 存档与时间边界

数据保存在**当前浏览器、当前网站来源**的 localStorage，最多 20 份农场。更换端口、域名、浏览器或设备会进入不同存档空间。隐私模式和清理网站数据可能使数据消失，请定期导出。手机与电脑不会自动同步，使用 JSON 手动转移。

每次成功操作立即保存，另每 15 秒保存一次，切后台/pagehide 再保存。异常终止在无操作时最多丢失最近一次自动保存后的时间基线，不会因刷新重置播种时间。多标签页通过保存修订号和 storage 事件阻止旧页覆盖新页，发生冲突时可导出当前副本或重新载入。

时间倒退时保留成长剩余时间，不发放倒退区间收益。**纯本地游戏不能真正防止系统时间修改、开发者工具修改存档或导入被修改的合法 JSON**；目前是进度校验与离线上限保护，不是服务器可信防作弊。委托使用设备本地日期，不进行网络校时。

## 项目结构与未来适配

```text
src/game/       纯游戏规则、存档类型、导入校验；不调用 document、localStorage、wx
src/data/       商品、经济数值、熟练度、音频旋律 JSON
src/platform/   Web 平台实现；存档仓库；StorageAdapter / AudioAdapter / PlatformAdapter
src/ui/         纯视图、项目自绘像素 SVG 图标
src/main.ts     H5 DOM 交互、平台组合、生命周期与轻量垂钓动画
src/style.css   电脑/手机响应式样式
public/art/     本地像素场景，无运行时图片服务依赖
scripts/        生产离线缓存清单生成
```

详见 [平台适配设计](docs/architecture.md) 与 [验证记录](docs/verification.md)。所有 `wx.*` 和 macOS 原生桥接都留给未来平台实现，不进入游戏规则。H5 DOM/CSS 界面不能直接变成原生微信 WXML，需要另写小程序视图或评估承载方式。

## 依赖与素材

无运行时 npm 框架依赖。开发依赖仅 Vite、TypeScript、tsx（测试执行）；生产 JS 当前约 70KB，gzip 约 26KB，CSS 约 40KB，gzip 约 10KB，以构建输出为准。本地像素场景 PNG 合计约 7.7MB，首屏主要加载地图约 3.1MB；生产离线安装会预缓存全部场景。未引入第三方游戏引擎、外部字体、CDN 或分析服务。

`public/art/world.png`、`farm.png`、`ranch.png` 使用内置 ImageGen 按已确认 UI 风格生成，属于本项目 AI 生成场景，**并非 CC0 素材**。物品图标按用户提供的《物品分类.xlsx》原图使用。`src/ui/icons.ts` 中 SVG 像素图标和音频旋律由本项目自绘/合成。提示词与来源记录见 [素材说明](docs/art.md)。开发阶段占位图已由本地场景和自绘图标替换；后续若引入第三方素材须单独核对授权。

旧版 20×15 存档会自动迁移至 30 格：优先保留作物及原倒计时，再保留已耕地。超出容量的作物转入 `farm.pendingCrops`，继续原倒计时，可在农场领取；离线期间遵循原四小时结算上限，金币、物品、熟练度和委托不重置。导出的新存档不兼容升级前的旧程序。

快捷播种：种子篮横向展示全部种子与库存，支持触屏左右滑动和鼠标横向拖动。点选种子后点空地可连续播种；长按种子约 350ms 后拖过多个空地，预览高亮，松手统一播种并保存。电脑端选中种子后可直接向上拖动。未开垦/已种植地块和重复划过的格子自动跳过，最多播种当前库存数量；取消、切后台或失焦不扣种子。页面边缘支持拖种时自动滚动。
