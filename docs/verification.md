## 建议的三步手工验收

1. `npm run dev`，新建农场。进入农场，收取初始萝卜，点一块已耕空地播种并浇水；刷新后继续存档，确认作物和倒计时保留。
2. 同 Wi-Fi 的手机打开终端 Network 地址。依次进入五大板块、打开商店和背包，购买并放入一尾鱼苗，确认按钮和面板均可操作。首次在线载入需要网络，但无外部 API 请求。
3. 导出 JSON，切后台一段时间后返回并领取离线仓库；导入先前备份，确认它创建第二份独立农场。生产离线访问需先 `npm run build && npm run preview`，在线加载并等待缓存完成后再断网验证。
