# 本地素材记录

本轮使用内置 ImageGen 生成 3 张场景 PNG，无外部运行时依赖。它们是 AI 生成项目素材，不标注为 CC0。最终人工确认参考为聊天中的「我的星星农场 · 比例调整版」。

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| `public/art/world.png` | 五区域大地图；小镇、鱼塘、神秘商店局部场景 | 内置 ImageGen，以确认稿为风格参考 |
| `public/art/farm.png` | 农田底图；上层叠加实际 20×15 网格与作物状态 | 内置 ImageGen，以 world.png 为风格参考 |
| `public/art/ranch.png` | 无动物的牧场底图；上层叠加可点击动物与产出 | 内置 ImageGen，以 world.png 为风格参考 |
| `src/ui/icons.ts` | SVG 像素作物、动物、物品、功能图标 | 项目自绘矢量路径 |
| `src/data/audio.json` | 24 秒原创合成循环旋律 | 项目合成，Web Audio 实时播放 |

## 提示词摘要（ui-mockup / illustration-story）

- World：与确认稿保持一致的温暖可爱 16-bit 清晰像素风。竖幅 2:3，五个区域通过蜿蜒小径相连：左上黄屋顶农场、右上红色畜棚、左中锦鲤池、右中小镇、下中紫色神秘帐篷。樱花、春草、远山和右下瀑布。不要人物、UI、文字、标签或按钮。
- Farm：与 World 同风格的正交俯视农场。上部小屋、水井与树冠；中心 x4–96%、y23–94% 为留空的淡绿色长方形草地，供动态网格覆盖。外侧细木栅栏，底图不绘制网格、作物、人物、文字或 UI。
- Ranch：与 World 同风格的俯视牧场。顶部鸡舍与红畜棚，下部约 70% 为可放置动物精灵的开阔草地。外侧木栅栏、樱花、少量花草和水槽。不要动物、人物、文字、标签或 UI。

原始生成提示强调原生本地游戏背景，不将概念 UI 整图当成可交互页面。农场各格作物、牧场动物、倒计时、价格和按钮均由真实状态渲染。
